# Badi-Journal

Betriebsjournal für das Schwimmbad: Messwerte per Tablet erfassen, am Büro-PC auswerten, bearbeiten und als PDF drucken.

- Nur Python 3.9+ nötig, keine weiteren Pakete
- Tablet: erfassen + anzeigen · PC (`http://localhost:8080`): bearbeiten, löschen, PDF-Bericht, CSV-Export/-Import, Änderungsprotokoll
- Automatisches CSV- und Datenbank-Backup bei jeder Änderung
- `Notfall_Excel_Vorlage.xlsx` liest die CSV-Backups ohne Programm

Installation und Bedienung: siehe [LIESMICH.txt](LIESMICH.txt).
